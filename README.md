# Cartera Vencida

Static site for [carteravencida.com](https://carteravencida.com), published with GitHub Pages.

Lead forms post JSON from `form.js` to FormSubmit so each submission notifies rrlegal82@gmail.com. That inbox must confirm FormSubmit’s first activation email before live submits are delivered. This repo has no Cloudflare Worker; production uses FormSubmit for now.
